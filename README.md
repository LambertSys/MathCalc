Проект компилятора + виртуальная машина.  

Реализовано на данный момент:
- Разбор С-подобного языка через рекурсивный спуск;
- Грамматика для языка;
- AST дерево + утилиты для него, типо вывода в graphviz;
- Семантический анализ
- Мини виртуальная стековая машина со своим байт-кодом.

В разработке:
- IR, оптимизации и другие трансформации;
- Генерация байт-кода для виртуальной машины из IR кода;
- Генерация IR кода из AST.
